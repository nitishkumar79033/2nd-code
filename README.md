Python Programming Practice

Welcome to my Python programming practice repository!

This repository contains Python programs created and executed using Databricks Notebooks.

Technologies Used

- Python
- Databricks
- Git

Programs Included

1. Prime Number – Check whether a number is prime or not.
2. Even or Odd Number – Identify whether a number is even or odd.
3. Palindrome Number – Check whether a number is a palindrome.
4. Factorial number - Calculate factorial of a number.
5. Fabonacci series - Generate the fabonacci sequence up to the given number of terms.
